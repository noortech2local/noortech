Demo privacy

Updated 25 September 2026

This is a public product demonstration. Noor Tech does not ask for or collect names, email addresses, account details, payment details, device location or wearer profiles through this demo. There are no sign-up forms, analytics, advertising trackers or individual NFC scan statistics.

The demo uses locally hosted content. Location lookup, online city search, live prayer times, notifications and external audio are disabled. The inspiration page draws from Arabic verses and English translations bundled with the site, without external API calls. Language and favourite choices on that page last only until it reloads; the demo does not save them in cookies or browser storage. It removes legacy Noor Tech saved preferences when the inspiration page opens.

The website host still receives the connection information needed to deliver pages. GitHub Pages logs visitor IP addresses for security. These hosting records are separate from the demo's features; this is not a promise of zero data processing by the hosting provider. See GitHub Pages documentation.

Demo bracelets should link to a shared public page, without personal identifiers. Anyone with that link can view its content. Accounts, sign-ups, ordering and personalised services are outside this demo and need a separate privacy review before introduction.

خصوصية العرض التجريبي

آخر تحديث: 25 سبتمبر 2026

هذا عرض عام للمنتج. لا تطلب نور تك ولا تجمع عبر هذا العرض الأسماء أو عناوين البريد الإلكتروني أو بيانات الحسابات أو الدفع أو موقع الجهاز أو الملفات الشخصية لمرتدي السوار. لا توجد نماذج تسجيل أو أدوات تحليل أو تتبع إعلاني أو إحصاءات فردية لمسح NFC.

يستخدم العرض محتوى مستضافاً محلياً. خدمات تحديد الموقع والبحث عن المدن ومواقيت الصلاة المباشرة والإشعارات والصوت الخارجي غير مفعّلة. تعرض صفحة الإلهام آيات عربية وترجمتها الإنجليزية المضمّنة في الموقع دون طلبات إلى خدمات خارجية. تستمر اختيارات اللغة والمفضلة في تلك الصفحة حتى إعادة تحميلها فقط، ولا تُحفظ في ملفات تعريف الارتباط أو تخزين المتصفح. تُحذف تفضيلات نور تك القديمة المحفوظة عند فتح صفحة الإلهام.

يتلقى مزوّد الاستضافة معلومات الاتصال اللازمة لعرض الصفحات. تسجّل خدمة GitHub Pages عناوين IP لأغراض الأمان. هذه السجلات منفصلة عن وظائف العرض، ولا يعني ذلك انعدام معالجة البيانات لدى مزوّد الاستضافة.

ينبغي أن تفتح أساور العرض صفحة عامة مشتركة دون معرّفات شخصية. يمكن لأي شخص يملك الرابط مشاهدة محتواها. الحسابات والتسجيل والطلبات والخدمات الشخصية خارج نطاق هذا العرض، وتحتاج إلى مراجعة خصوصية منفصلة قبل تقديمها.
