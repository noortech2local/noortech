Demo privacy

Updated 26 September 2026

This is a public product demonstration. Noor Tech has no personal-data database for this demo and does not ask for names, email addresses, account details, payment details or wearer profiles. Optional location and city choices are processed in browser memory, not sent to a Noor Tech application server. There are no sign-up forms, analytics, advertising trackers or individual NFC scan statistics.

Live features are optional. Using device location sends coordinates directly from your browser to AlAdhan for prayer times and BigDataCloud for the city name. City searches go directly to Open-Meteo. Music is streamed from SoundHelix when requested, with no audio preload on entry. These providers receive connection information such as your IP address and may retain their own logs; Noor Tech cannot guarantee their retention practices. You control browser location and notification permissions. Reminders operate while the page is open. The inspiration page draws from Arabic verses and English translations bundled with the site, without external API calls. Location, city, reminder, language and favourite choices on that page last only until it reloads; the demo does not save them in cookies or browser storage. It removes legacy Noor Tech saved preferences when the inspiration page opens.

The website host still receives the connection information needed to deliver pages. GitHub Pages logs visitor IP addresses for security. These hosting records are separate from the demo's features; this is not a promise of zero data processing by the hosting provider. See GitHub Pages documentation.

Demo bracelets should link to a shared public page, without personal identifiers. Anyone with that link can view its content. Accounts, sign-ups, ordering and personalised services are outside this demo and need a separate privacy review before introduction.

خصوصية العرض التجريبي

آخر تحديث: 26 سبتمبر 2026

هذا عرض عام للمنتج. لا توجد قاعدة بيانات شخصية لدى نور تك لهذا العرض، ولا نطلب الأسماء أو البريد الإلكتروني أو بيانات الحسابات أو الدفع أو الملفات الشخصية. يُعالَج الموقع واختيار المدينة في ذاكرة المتصفح ولا يُرسلان إلى خادم تطبيق تابع لنور تك. لا توجد نماذج تسجيل أو أدوات تحليل أو تتبع إعلاني أو إحصاءات فردية لمسح NFC.

الميزات المباشرة اختيارية. يرسل استخدام موقع الجهاز الإحداثيات مباشرة إلى AlAdhan لمواقيت الصلاة وBigDataCloud لاسم المدينة. تُرسل عمليات البحث عن المدن إلى Open-Meteo، ويُحمّل الصوت من SoundHelix عند طلبه دون تحميل مسبق عند فتح الصفحة. تتلقى هذه الجهات معلومات اتصال مثل عنوان IP وقد تحتفظ بسجلاتها؛ لا تضمن نور تك سياسات الاحتفاظ لديها. تتحكم أنت في أذونات الموقع والإشعارات. تعمل التذكيرات أثناء بقاء الصفحة مفتوحة. تعرض صفحة الإلهام آيات عربية وترجمتها الإنجليزية المضمّنة في الموقع دون طلبات إلى خدمات خارجية. تستمر اختيارات الموقع والمدينة والتذكيرات واللغة والمفضلة في تلك الصفحة حتى إعادة تحميلها فقط، ولا تُحفظ في ملفات تعريف الارتباط أو تخزين المتصفح. تُحذف تفضيلات نور تك القديمة المحفوظة عند فتح صفحة الإلهام.

يتلقى مزوّد الاستضافة معلومات الاتصال اللازمة لعرض الصفحات. تسجّل خدمة GitHub Pages عناوين IP لأغراض الأمان. هذه السجلات منفصلة عن وظائف العرض، ولا يعني ذلك انعدام معالجة البيانات لدى مزوّد الاستضافة.

ينبغي أن تفتح أساور العرض صفحة عامة مشتركة دون معرّفات شخصية. يمكن لأي شخص يملك الرابط مشاهدة محتواها. الحسابات والتسجيل والطلبات والخدمات الشخصية خارج نطاق هذا العرض، وتحتاج إلى مراجعة خصوصية منفصلة قبل تقديمها.
